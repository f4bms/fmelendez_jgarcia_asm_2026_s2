## Etapa 2: Implementación de la DFT y FFT
En esta etapa se implementaron las funciones de la DFT y la FFT radix-2, y se compararon sus tiempos de ejecución para diferentes tamaños de señal. Se generaron gráficas log-log para visualizar la eficiencia de cada algoritmo. Además, se generan graficas de magnitud y fase para diferentes señales de prueba para analizar los principales efectos de cada una de las señales.

Para ejecutar esta etapa, ejecute make all.
